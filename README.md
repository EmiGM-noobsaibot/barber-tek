# Barber-Tek 💈

![License](https://img.shields.io/badge/license-pending-lightgrey)
![Tech](https://img.shields.io/badge/stack-Java%20%7C%20Next.js%20%7C%20Python-blue)

**Barber-Tek** es un **SaaS modular** diseñado para cubrir las necesidades de diferentes tipos de negocios.  
El caso de uso inicial es una **barbería**, pero la arquitectura permite adaptarse a otros giros como restaurantes, tiendas de ropa, gimnasios, etc.  



---

## 🚀 Características principales

- 📊 **Dashboard de datos**  
  - Visualización de ventas y clientes.  
  - Reportes dinámicos con gráficos interactivos.  
  - Integración de modelos de **predicción** (ventas, cortes, tendencias).  
  - Filtros por semana, mes o año.  

- 💵 **Punto de venta (POS)**  
  - Gestión de ventas y cotizaciones.  
  - Registro de compras y stock.  
  - Emisión de tickets y facturas.  
  - Compatible con distintos rubros.  

- 🤖 **Chatbot inteligente**  
  - Integración con **WhatsApp** y **correo electrónico**.  
  - Automatización de pedidos, cotizaciones y reservas.  
  - Modelo NLP (Procesamiento de Lenguaje Natural) adaptable al giro.  

- 🔧 **Arquitectura modular**  
  - Cada módulo (Dashboard, POS, Chatbot) puede funcionar de manera independiente.  
  - Escalable para añadir más funcionalidades.

## 🛠️ Tecnologías utilizadas

### Frontend
- [Next.js](https://nextjs.org/) – React Framework para UI.  
- [TailwindCSS](https://tailwindcss.com/) – Estilos rápidos y responsivos.  
- [Recharts](https://recharts.org/en-US/) – Gráficos interactivos para dashboards.  

### Backend
- [Java](https://www.java.com/)  
- [Spring Boot](https://spring.io/projects/spring-boot) – Microservicios y APIs REST.  

### Inteligencia Artificial
- [Python](https://www.python.org/)  
- [Scikit-learn](https://scikit-learn.org/) – Modelos de predicción.  
- [TensorFlow](https://www.tensorflow.org/) (futuro) – Modelos avanzados de ML/DL.  

### Chatbot & Mensajería
- [Twilio API](https://www.twilio.com/whatsapp) – Integración con WhatsApp.  
- [SMTP](https://en.wikipedia.org/wiki/Simple_Mail_Transfer_Protocol) – Envío de correos.
